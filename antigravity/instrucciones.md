# Objetivo del proyecto

Crear una aplicación para un formulario de solicitud de citas con informacion basica de la persona que requiere el servicio y que pueda enviar la informacion a una base de datos.

El proyecto ya está creado y con tailwind instalado, pero sin estilos ni funcionalidades. El objetivo es implementar el diseño y las funcionalidades básicas de una app de citas moderna, premium y minimalista, siguiendo exactamente los diseños presentados en las referencias que serán proporcionadas que se encuentran en la carpeta de "Antigravity" dentro del proyecto.
